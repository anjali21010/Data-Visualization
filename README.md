# COVID-19 Data Visualization Project

## Project Overview
This project analyzes COVID-19 data using Python, Pandas, and Matplotlib. It displays data summaries and visualizes confirmed cases through bar charts.

## Objectives
- Load COVID-19 data from a CSV file.
- Explore dataset rows and columns.
- Analyze confirmed cases by date and country.
- Create bar charts for data visualization.
- Display a basic data analysis summary.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

## Project Files
- `week2_visualization.py` — Python source code.
- `covid_last_10_dates.png` — Bar chart for the last 10 dates.
- `top_10_countries.png` — Bar chart of the top 10 countries.
- CSV files — COVID-19 datasets used for analysis.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Keep the Python file and required CSV dataset in the correct folders.
4. Run:
   `python week2_visualization.py`

## Output
The project generates two bar charts and prints a COVID-19 data analysis summary in the terminal.

## Learning Outcomes
This project demonstrates basic data loading, grouping, sorting, summary analysis, and visualization using Python.
